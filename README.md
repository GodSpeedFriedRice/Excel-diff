# Excel-diff

Excel ファイルやフォルダを比較する Windows デスクトップアプリ。左右でシートを見比べ、値・数式・書式や表示設定の違いを確認できる。共通ベースがある場合は、3方向マージでセルの変更を取り込める。

## サンプルで試す

.NET 10 SDK を入れた Windows で、リポジトリのルートから起動する。

```powershell
dotnet run --project src/ExcelDiff.Desktop
```

1. 「比較…」を押し、「フォルダ比較」を選ぶ。
2. 左に [samples/before](samples/before)、右に [samples/after](samples/after) を指定して「比較」を押す。
3. 結果のファイル行をダブルクリックして詳細を開く。全体プレビューは A1 から始まり、Ctrl+↑ / Ctrl+↓ で差分をたどれる。

ファイル一覧や差分一覧の列見出しをクリックすると並べ替えられる。同じ見出しをもう一度クリックすると逆順になる。

メインの各タブは × または Ctrl+W で閉じられる。最後のタブを閉じても、メニューから次の比較を開ける。次回起動時は、終了時のウィンドウサイズと最大化状態を復元する。

サンプルはすべて架空データ。同名の Excel ファイルが左右に7冊ずつあり、見積書の明細追加、工程表の行削除、5,000行目付近の在庫数量変更、納品確認書の印鑑画像などを試せる。

## ブック全体の差分

ファイル比較の「ブック全体の差分」では、`.xlsx` 内の部品をパスごとに比較する。変更された部品を選ぶと、XML・参照ファイルは左右のコード差分を表示し、画像・埋め込みファイルなどはサイズと SHA-256 を表示する。部品内のバイトを比較するため、再保存時の内部 ID や XML の空白の違いも検出する。ZIP の圧縮方法やエントリ順は比較に含めない。

フォルダ比較では、セルなどが同じでも部品が変わっていれば「部品に差分あり」と表示する。

## 3方向マージ

1. 「ファイル」→「3方向マージ…」を開く。
2. 共通ベース、取り込み1、取り込み2のフォルダを指定して「比較」を押す。サブフォルダを含め、同じ相対パスの `.xlsx` を対応付ける。「フォルダを指定」のチェックを外すと、3冊を直接選べる。
3. ファイル一覧からブックを選び、「詳細を開く」かダブルクリックで詳細タブを開く。コンフリクトするセルごとに「取り込み1を採用」または「取り込み2を採用」を押す。「プレビュー」を選ぶと全体プレビューから開ける。
4. 全ファイルのセルコンフリクトを解決したら「結果フォルダに保存…」で親フォルダを選ぶ。その下に `<取り込み1のフォルダ名>-merged` を作る。1冊ずつ指定した場合は「別名で保存…」を使う。

次に3方向マージを開くと、前回の解析に使った3つのパスとフォルダ指定の設定が入力欄に戻る。

ファイル一覧はファイル名、フォルダ、状態、未解決セルの件数で並べ替えられる。コンフリクトの行は黄色で表示し、解消が不要な変更は「差分あり（コンフリクトなし）」と表示する。詳細ではセル差分の処理やブック内部の比較結果でも並べ替えられる。

結果フォルダには、取り込み1にある `.xlsx` を相対パスを保って出力する。3版が揃わないブックや解析できないブックは「コンフリクト（手動解消）」と表示する。取り込み1にある対象外のブックはそのままコピーし、取り込み2からのファイル追加や削除は手動で行う。

### 3方向マージをサンプルで試す

[samples/merge](samples/merge) の [base](samples/merge/base)、[production](samples/merge/production)、[incoming](samples/merge/incoming) をそれぞれ指定する。各フォルダには見積書 `quote.xlsx` と、サブフォルダの納品確認書 `reports/delivery.xlsx` がある。次の表は見積書の解析結果。

| セル | 共通ベース | 取り込み1 | 取り込み2 | 解析結果 |
| --- | ---: | ---: | ---: | --- |
| C5（受付端末の数量） | 2 | 3 | 4 | コンフリクト |
| D5（受付端末の単価） | 80,000 | 78,000 | 80,000 | 取り込み1を保持 |
| C6（付属品の数量） | 3 | 4 | 4 | 両側で同じ変更 |
| D7（設置・動作確認の単価） | 25,000 | 25,000 | 26,000 | 自動取り込み |

C5 で取り込み2を採用して保存すると、Excel で開いたときの合計は 410,000 円、取り込み1を採用したときは 332,000 円になる。

同じシート名・セル番地の値と通常の数式を比較する。取り込み2だけの変更は自動で採用し、取り込み1だけの変更や両側で同じ変更は取り込み1の内容を保持する。両側で別の変更をしたセルはコンフリクトになる。

解析後は「ブック全体の差分」で、それぞれの版を共通ベースと比べた結果を確認できる。「両側で別の変更」は同じ部品の内容が両側で異なることを示す。1つのシート XML に別々のセル編集が入ることもあるため、解消が必要なセルは「差分・コンフリクト」で確認する。部品一覧は確認用で、保存にはセル差分の採用結果が反映される。

全体プレビューと XML は共通ベース・取り込み1・取り込み2を横に並べて表示する。「設定」→「3方向マージで3列表示」のチェックを外すと、表示する2版を選べる。シートのスクロールと Ctrl+ホイールでの拡大縮小は連動する。

書式・画像・行高・列幅は取り込み1を引き継ぐ。シートの追加・削除・名前変更、結合範囲の変更、検出した行・列の移動、共有・配列数式やセル内の文字装飾は対象外として表示する。行・列の挿入や削除、並べ替えがある場合は、対応するセル番地を Excel で確認してから利用する。マージ結果の数式は Excel で開いたときに再計算される。

## プレビューの画像サイズ

シート上の PNG・JPEG は、プレビュー用画像の長辺を既定で 512 px に抑え、Excel 上の配置サイズで表示する。必要に応じて、起動前に環境変数 `EXCEL_DIFF_IMAGE_MAX_EDGE` を 1～2048 の整数で設定できる。

```powershell
$env:EXCEL_DIFF_IMAGE_MAX_EDGE = '768'
dotnet run --project src/ExcelDiff.Desktop
```

全体プレビューでは、四角形・角丸四角形・楕円・三角形・ひし形・矢印・線・テキストボックスなどの挿入図形も表示する。グループ化された図形や未対応の形状は枠と名前で示す。図形や画像のファイル内部の変更は「ブック全体の差分」で確認できる。

## ディレクトリ構成

| パス | 役割 |
| --- | --- |
| `docs/` | 画面設計と比較仕様 |
| `src/ExcelDiff.Desktop/Views/` | C#／WinForms の比較対象選択、フォルダ比較、Excel 差分詳細 |
| `src/ExcelDiff.Core/Workbooks/` | `.xlsx` の読み込みと比較用データの組み立て |
| `src/ExcelDiff.Core/Comparison/` | ファイルの対応付け、シート・セル・設定の差分判定 |
| `tests/ExcelDiff.Core.Tests/` | 比較処理のテスト |
| `samples/` | フォルダ比較と3方向マージを試すための帳票 |

Desktop は入力と結果の表示を担当し、Core は画面に依存せず比較結果を返す。ソリューションとプロジェクトファイルは実装開始時に作成する。
