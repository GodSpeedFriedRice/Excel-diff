# 画面設計

Windows 向けの C#／WinForms アプリ。左を変更前、右を変更後として全画面で統一する。

## 画面遷移

- フォルダ比較は対象選択 → フォルダ比較一覧 → Excel 差分詳細。ブックを開くと比較一覧と詳細をタブで行き来できる。
- ファイル比較は対象選択 → Excel 差分詳細。左右に指定した 2 ファイルをそのまま比較する。

## 01 比較対象を選択

「フォルダ比較」「ファイル比較」を切り替え、左右のパスを直接入力するか「参照…」で選ぶ。フォルダ比較では「サブフォルダも比較する」を選べる。「比較」の前にパスの存在と選択モードに合う種類を確認する。ファイル比較の対象拡張子は `.xlsx`。

[Figma の比較対象選択](https://www.figma.com/design/tixG6X3mqPyC5fGSZDMlvP/?node-id=1-3)

## 02 フォルダ比較

左右のルートパスを表示し、フォルダごとにファイル名、比較結果、左右の更新日時、拡張子を並べる。結果は「差分あり」「同一」「左のみに存在」「右のみに存在」「比較できません」。色と文言で識別でき、下部に結果別の件数を表示する。

「開く…」「再比較」「前の差分」「次の差分」「同一ファイルを表示」を用意する。「シートまで差分を見る」はブック内容を調べる比較オプション。判定案は[比較仕様](comparison-design.md#フォルダ比較)を参照する。比較できるペアは一覧から詳細タブで開く。

[Figma のフォルダ比較](https://www.figma.com/design/tixG6X3mqPyC5fGSZDMlvP/?node-id=1-54)

## 03 Excel 差分詳細

シートごとに差分件数を表示し、変更前と変更後を左右に並べる。「差分のある行だけ」で絞り込み、「前へ」「次へ」で差分を移動する。左右のスクロールを連動させ、行番号は各ブックの元の番号を表示する。

Figma では変更セルを黄、追加行を緑、削除行を赤で示す。片側に対応する行がない場合は反対側に「対応する行なし」を表示する。選択した差分について、画面下部に種別、左右のセル番地、変更前後の値を表示する。元の書式を確認するときは、差分色を切り替えられるようにする。

設定差分、倍率切り替え、XML コードビューの配置と操作は今後の設計課題。設定差分には項目名と左右の値を表示する。倍率は、同じ倍率での比較と各ブックの保存倍率での比較を区別する。
