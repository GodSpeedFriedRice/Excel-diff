# 画面設計

Windows 向けの C#／WinForms アプリ。左を変更前、右を変更後として全画面で統一する。

## 画面遷移

- フォルダ比較は対象選択 → フォルダ比較一覧 → Excel 差分詳細。ブックを開くと比較一覧と詳細をタブで行き来できる。
- ファイル比較は対象選択 → Excel 差分詳細。左右に指定した 2 ファイルをそのまま比較する。

## 01 比較対象を選択

「フォルダ比較」「ファイル比較」を切り替え、左右のパスを直接入力するか「参照…」で選ぶ。フォルダ比較では「サブフォルダも比較する」を選べる。「比較」の前にパスの存在と選択モードに合う種類を確認する。ファイル比較の対象拡張子は `.xlsx`。

[Figma の比較対象選択](https://www.figma.com/design/tixG6X3mqPyC5fGSZDMlvP/?node-id=1-3)

## 02 フォルダ比較

左右のルートパスを表示し、フォルダごとにファイル名、比較結果、左右の更新日時、拡張子を並べる。結果は「差分あり」「同一」「左のみに存在」「右のみに存在」「比較できません」。色と文言で識別でき、下部に結果別の件数を表示する。

「開く…」「再比較」「前の差分」「次の差分」「同一ファイルを表示」を用意する。「シートまで差分を見る」をオンにすると、比較できたファイルの下にシート名と比較結果が表示される。差分があるシートには件数も表示する。ファイル行またはシート行から詳細タブを開ける。シート行から開くと、そのシートが選択される。

[Figma のフォルダ比較](https://www.figma.com/design/tixG6X3mqPyC5fGSZDMlvP/?node-id=1-54)

## 03 Excel 差分詳細

シートごとに差分件数を表示する。差分一覧には場所、変更項目、変更前、変更後を並べ、「前へ」「次へ」で差分を選択できる。結合セルは一覧の1行にまとめ、選択すると変わった項目を下部に表示する。

「周辺を表示」をオンにすると、選択した差分の周辺を左右に並べる。「全体プレビュー」タブではシート全体を左右でスクロールできる。差分一覧の行をダブルクリックすると、全体プレビューでその場所を開く。描画済みの画像はスクロールしても再利用する。差分は色付きの枠で表示し、行・列の設定変更は見出しに示す。セルや見出しをクリックすると、その場所の差分または値を画面下部に表示する。行番号と列名は各ブックの元の位置を示す。「保存倍率」で各ブックの表示倍率を適用できる。XML タブではシートの XML を左右に表示する。詳細タブは右端の `×` または Ctrl+W で閉じる。

[Figma の Excel 差分詳細](https://www.figma.com/design/tixG6X3mqPyC5fGSZDMlvP/?node-id=1-208)
