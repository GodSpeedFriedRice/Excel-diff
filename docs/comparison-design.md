# 比較仕様

初版は 2 つの `.xlsx` の読み取りと差分確認を対象にする。差分の取り込み、Excel ファイルへの書き戻し、3 ファイル比較は将来の範囲。画像、グラフなどの比較対象外の要素は、対応範囲を明示する。

## フォルダ比較

- 左右のルートからの相対パスでファイルを対応付ける。フォルダ指定の比較の場合、サブフォルダまで含める
- 両側にあるファイルは常にブックの内容を比較する。「シートまで差分を見る」は、ファイルの下に各シートの結果を表示する設定。更新日時は一覧の参考情報として表示する。
- 片側にしか存在しないファイルは左右別に扱う。読み込みに失敗したファイルは「比較できません」とし、他のファイルの比較は続ける。内容比較で「同一」と表示する場合は、比較対象項目が一致したことを示す。

## ブック比較

`.xlsx` の内容を読み込み、ブック、シート、行列、セルと書式の情報に整理する。差分結果はシート名、左右のセル位置、変更種別、項目名、変更前後の値を持つ。シート単位や印刷設定などの差分では、セル位置の代わりに設定の対象を示す。XML コードビューは関連箇所を調べるための補助表示とする。

| 分類 | 比較項目 |
| --- | --- |
| セルの内容 | 値、数式。表示結果が同じでも数式の変更を識別する |
| フォントと配置 | フォント名、サイズ、装飾、色、横・縦位置、インデント、文字の回転 |
| 文字の収め方 | 折り返して全体を表示、縮小して全体を表示 |
| 表示形式と装飾 | 数値・日付などの表示形式、背景色、罫線 |
| シートとレイアウト | シートの追加・削除・順序、列幅、行高、結合セル、行列の非表示 |
| 表示設定 | 保存された表示倍率、ウィンドウ枠の固定 |
| 印刷設定 | 印刷倍率、ページへの収め方、用紙、向き、余白、印刷範囲 |

結合セルは左上のセルで対応付け、値・数式・書式・範囲の変更を1件にまとめる。列幅や行高、行・列から継承する書式は行・列の設定として1件にまとめる。同じ変更が連続する場合は行・列の範囲として表示する。結合解除後に独立したセルに入力された値も比較する。

周辺プレビューは選択した差分の近くを、全体プレビューはシート全体を表示する。どちらも列幅、行高、結合セルと基本書式を表示する。折り返しや縮小が指定されていない文字列は、右隣の空セルに表示が続き、値や数式のあるセルまたは結合範囲で止まる。結合セル内の文字は結合範囲の幅で表示する。画面の表示倍率と印刷倍率は別項目として扱う。書式など見た目だけでは判断しにくい項目は、設定値を左右に並べる。

## 行・列の対応付け

Figma の商品マスタでは、削除行と追加行に対応する空白行を反対側に表示し、元の行番号を保っている。実装時は、固定帳票のセル番地ベースの比較と、一覧表でキー列を使って行を対応付ける比較を検討する。キーの選択方法、重複・欠落時の扱い、列の増減とシート名変更の判定は実装前に決める。

## 実装時の確認ケース

- 値が同じでも、数式、フォントサイズ、折り返し、縮小表示の違いを個別に表示できる。
- 表示倍率と印刷倍率が独立して検出される。
- 行を途中で追加・削除した一覧では、対応付けの結果が左右のプレビューと差分件数に反映される。
- フォルダ比較では、左右のみのファイルと比較できないファイルを区別し、比較できるペアを開ける。
